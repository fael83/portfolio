# Portofolio Pribadi

Buka `index.html` langsung di browser, atau di VS Code pasang ekstensi **Live Server** lalu klik "Go Live".

## Yang diedit
- **Semua isi** (nama, foto, project, sertifikat, tech stack, sosial media, link CV): blok `CONFIG` di bagian atas `script.js`.
- **Tampilan** (warna, font, ukuran): `style.css`. Warna ada di `:root` paling atas.
- **Foto & gambar**: taruh di folder `assets/` lalu isi path-nya di CONFIG, contoh `photo: "assets/foto.jpg"`.
- **Form kontak**: daftar di formspree.io, tempel endpoint ke `formEndpoint`.

## Deploy ke Vercel
Upload folder ini ke GitHub, lalu Import di vercel.com. Tidak perlu build.
